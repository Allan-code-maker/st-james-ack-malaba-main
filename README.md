# St. James ACK Malaba — Official Website

The official website for **St. James Anglican Church of Kenya (ACK), Malaba**.  
Built on the Internet Computer (ICP) for secure, decentralized hosting.

## About the Church
St. James ACK Malaba serves the Malaba community through Sunday worship,  
youth programs, community outreach, and pastoral care.

## Tech Stack
- **Frontend:** React + TypeScript
- **Backend:** Motoko canister on the Internet Computer
- **Auth:** Internet Identity
- **Platform:** Caffeine AI (ICP deployment)

## Development
```bash
pnpm install
pnpm run build
```
